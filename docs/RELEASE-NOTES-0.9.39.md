## 本次包含（远端从 0.9.35 → 0.9.39，共 4 项）

### 1. 查不通时给「手工兜底」（0.9.36）

任何一家船司查不出结果，面板不再只丢一句死文案：

- 该行出现「手工查」按钮 → 展开**官网页链接**（单号自动复制到剪贴板）+ **粘贴框** + 「解析并填入」
- 粘一整段官网原文即可，自动认出「日期 · 事件 · 港口」
- 解析不出就**原文原样保留**并标「未解析」，不丢东西
- 手工来源三重着色：实心琥珀「手工」角标 + 行淡琥珀底 + 首列琥珀竖线
- 解析逻辑只有一个实现（`engine/tracking/manual-parse.mjs`），插件走桥的 `/parse-manual`，
  以后改解析口径**不用重装插件**

典型场景：OOCL 官网是 Cloudflare + CargoSmart 双重风控（两轮无头实测成功率 0），
自动查不通，手工查一次粘回来照样能进表、照样参与里程碑着色。

### 2. 摘掉 HelloWps 空脚手架（0.9.36）

`publish.xml` 里那条 `HelloWps`（WPS 文字）已摘除 —— 之前文字里挂着一个空选项卡。
表格里的 ShipTrack4 不受影响。改动前已备份 `publish.xml.bak-20261028`。

### 3. 查询中切表不再整轮作废（0.9.37）

**问题**：以前查询跑到一半切换工作表，整轮直接中止（「已完成的行保留」），只能重来。
一个表格不可能开着 10 分钟不切 tab。

**现在**：切表时查询继续跑，结果先攒着不写（绝不写进别的表）；**切回原表自动补上**。
只有目标工作簿被关掉才真中止。

### 4. 切回原表全自动补齐（0.9.38 / 0.9.39）

从「切回来点一下补齐」改成**切回来自己补**：2.5 秒轮询，检测到已回到原表就自动写回，
一个字都不用点。每写一格前都重核一次目标表，写到一半又被切走就立刻停，绝不多写一格。
「补齐回填」按钮保留作兜底与可见性，不再是必经路径。

## 已知限制（如实写）

- **OOCL 自动追踪仍未接入**：官方 Cloudflare JSD + CargoSmart 滑块，两轮无头探针成功率 0，
  今日复核站点未改版。走上面第 1 项的手工兜底。
- **WPS 是否允许对非活动工作表写值：未验证**。没有权威文档，桩也不模拟这个语义，
  试错代价是「静默写脏活动表」，不可逆。所以采用「只在活动表上写 + 回来自动补」，
  效果等价且不冒这个风险。
