# v0.9.44 · 马士基提单号查不到（.cn 静默 302）＋ 收尾卡在「97/97 · 剩约 0 秒」

爹地 2026-10-29 16:1x 的两条真机报障，两条都已定位到根因并修掉（引擎侧改在 ShipScheduleHub 仓库）。

## ① 马士基提单号：官网查得到，插件报查不到，白等 84 秒

**现场**：MSK 提单号官网页有数据，插件却返回「no tracking response captured」，耗时 84 秒。

**根因（抓包定位）**：适配器先开 `www.maersk.com.cn`。同一张单在这一站的壳资源
（`main-*.js` / `track-*.js`）全部 302，SPA 起不来 → 页面**永远不发** 那个
`api.maersk.com/synergy/tracking/...` 请求；而 `goto` 本身是 200（302 的是子资源，不影响导航成功），
旧逻辑「导航成功就 break」，于是死等到超时。国际站 `www.maersk.com` 同一张单立刻命中接口。

**改法**（`engine/tracking/maersk.mjs`）：

| 项 | 改前 | 改后 |
|---|---|---|
| 每站等待 | 整段超时（可达 84s） | **每站 8 秒窗口**（导航也算在窗口里） |
| 换站条件 | 只有「打不开」才换 | **窗口内没抓到 synergy 响应就换下一站**（不再死等） |
| 总预算 | 无硬上限 | **30 秒硬上限**，到点如实返回 |
| 站点顺序 | `.cn → .com` 一律 | **提单号：`.com` 优先**（本次报障形态）；箱号维持 `.cn` 优先 |
| 失败文案 | 「no tracking response captured」 | 写明**试过哪些站、各自卡在哪一步**（含页面自己给的提示） |
| 两站都 404 | 也报「没抓到」 | 如实报**「Maersk 查无此单」**（`notFound`，别再让用户以为是网络） |
| 拿到响应但没数据 | 直接报错 | 先换下一站再判（防止一站返回空壳就误判「查无」） |

直连 `api.maersk.com.cn` 不带浏览器会 401（两号都是）→ 浏览器链路保留，只修「换站与等待」。

**验证**：
- 真机 `/track?number=<爹地表里那张单>&carrier=maersk`：**4.2s 返回 ok:true，7 条事件**
  （改前 84.8s 返回 ok:false）。
- 箱号回归：同一张单的箱号仍 ok:true，数据不变。
- 确定性桩 `tests/maersk-host-fallback.mjs`（不联网）：两个本地假站复现「壳 200 但子资源 302、不发请求」
  → 断言 8 秒窗口后自动换站拿到数据；两站都坏时 30 秒内返回并把站点诊断写进错误文案。

## ② 查询完成后面板卡在「97/97 · 剩约 0 秒」

**根因**：`runBatch` 收尾是先 `flushWrites()`（**同步**批量写 + 读回校验，全在主线程）再复位 busy。
这段时间浏览器无法重绘，画面就停在最后一帧；而 `etaText` 在 `done === total` 时算出 `left = 0`，
照样拼出「剩约 0 秒」。

**改法**（`src/components/TaskPane.vue`）：

1. `etaText`：`done >= total`（或剩余 <1 秒）时返回空串 —— 跑完不再显示「剩约 0 秒」。
2. 写回**分段让出主线程**：每段最多 30 行（`window.__SHIPTRACK_WRITE_CHUNK__` 可覆盖），
   段间 `await new Promise(r => setTimeout(r, 0))`，段内仍是批量写（不多花 COM）。
3. 写回**独立进度**：进度条从「查询 97/97 · 剩约 3 分钟」变成「查询 97/97 · 写回 43/97」，
   查询与写回两个阶段在界面上分得清。
4. `busy` 语义摆正：收尾写回是 `await` 的，**写回全部写完才复位**；外层 `try/finally` 保证
   收尾即使抛异常也会 `finishBatch`（不会把面板锁死）。

**验证**（`scripts/state-probe.mjs` 新增 **H31**，120 行大表 + 每格注入同步 COM 模拟真机）：
- 全程进度条**从未出现**「剩约 0 秒」；
- 采样到「写回 3/12 → 6/12 → 9/12 → 12/12」——写回写到一半界面就重绘过了；
- 写回阶段心跳最大间隔 **107ms**（<400ms），主线程没被独占；
- 跑完进度条消失，120 行按行身份全部写对（0 错位）。
全量状态机探针 **33/33 通过**（原 32 条不回退）。
